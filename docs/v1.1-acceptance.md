# Agent Workflow Factory v1.1 验收记录

## 验收结论

Agent Workflow Factory `1.1.0` 的技术验收结果为 **PASS**。`dev`、`team`、`regulated` 三档复杂度预设、DeepSeek Harness 真实执行、SQLite 可信轨迹、SoftHSM PKCS#11 签名、无私钥重放和防篡改检测均已完成验收。

### 真实 DeepSeek Harness

- 官方 SDK 单节点与双 Agent 多节点 Live Test 通过；
- 真实持久化运行结果为 `PASS`，原始签名轨迹重放为 `PASS`；

### 可信运行与防篡改

- `regulated` 档位正确强制 SQLite、运行签名、离线根信任、Worker 租约和 365 天默认保留期；

- 篡改副本不会影响原始运行目录和原始可信证据。

### SoftHSM 与 PKCS#11

- SoftHSM Token 初始化和 Ed25519 密钥对生成通过；
- 私钥保留在 Token 内，只导出 32 字节 Ed25519 公钥；
- HSM 公钥成功登记到独立信任库，并通过测试离线根重新签署和验证；
- 仓库内置 `tests.test_pkcs11_live` 通过，Token 实际完成规范化 JSON 的 Ed25519 签名；
- `regulated profile-check` 接受完整 PKCS#11、信任库和离线根配置；
- 真实 DeepSeek + SoftHSM 端到端运行通过，事件与检查点由 Token 内密钥签署；
- 在不提供 HSM PIN 的子 Shell 中，仅使用信任库公钥和离线根即可成功重放。

修复后的离线全量回归结果如下；三个跳过项正是已经在上述 WSL 验收中单独通过的 DeepSeek 单节点、DeepSeek 多节点和 PKCS#11 Live Test：

- WSL2 Ubuntu 24.04：`Ran 80 tests`，`OK (skipped=3)`；

## 尚未获得的生产声明

以下事项仍属于目标部署环境或后续版本范围，不能由本次 SoftHSM 验收代替：

- 真实 HSM 厂商对 Ed25519 Object 属性、并发会话、故障恢复和密钥轮换的认证；
- 组织级审计、法律、隐私和数据保留策略批准；
- 外部不可回滚时间戳、透明日志或远程审计锚；
- 跨主机调度、分布式事件存储和故障接管；
- 人工审批、定时循环、补偿事务和业务评审控制面。

生产部署仍应使用独立凭据系统注入 PIN，禁止使用本地验收 PIN，禁止把 Token 存储、私钥、DeepSeek API Key 或运行密钥提交到 Git。
